# Any.body Art — web

## Nahrání na GitHub Pages
1. Do `assets/img/art/` nahraj fotky `1.jpg` až `13.jpg` (smaž přitom `PRIDEJ-FOTKY-SEM.txt`).
2. Celou tuhle složku nahraj do nového GitHub repa (Add file → Upload files).
3. Settings → Pages → Source: Deploy from branch → main / (root) → Save.

## Soubory
- `index.html` — ART (portfolio)
- `koncerty.html` — Koncerty
- `o-mne.html` — O mně + kontakt
- `assets/img/art/` — fotky pro galerii ART (1.jpg–13.jpg)

Koncerty a O mně zatím mají placeholder rámečky (šedé plochy) — reálné
koncertní fotky doplníme stejným postupem, až budou připravené.
